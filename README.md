# React Card Project

A responsive and reusable card-based UI project built using React.js. This project demonstrates component-based architecture, dynamic rendering, and clean UI design.

---

##  Features

- Reusable card components
- Dynamic data rendering using `map()`
- Responsive design for all devices
- Clean and modern UI
- Easy to customize and extend

---

##  Tech Stack

- React.js
- Tailwind CSS
- HTML5
- CSS3
